Academic Grade Tracker

A web app that answers the question every student has before a final: what mark do I actually need? It tracks weighted assessments across a full degree and projects each course and the overall average toward a target.

The problem
Spreadsheets count a missing mark as zero, and syllabi have edge cases, like a "best of two grading schemes" rule, that simple formulas get wrong.
What I built
A relational data model across three tables, a pure-Python calculation engine, input validation, and a dashboard with risk labels for each course and credit-weighted degree projections.
What it shows
Data modelling, defensive validation, 34 unit tests covering edge cases (a missing mark isn't zero, targets above 100% flagged as unattainable, no divide-by-zero), and keeping private data out of a public repo.
